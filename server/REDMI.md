# MERN Backend API

Backend API for a MERN stack application built with Node.js, Express.js, and MongoDB.

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- CORS
- dotenv

## Project Structure

server/
├── config/
├── controllers/
├── middleware/
├── models/
├── routes/
├── utils/
├── .env
├── .env.example
├── .gitignore
├── app.js
├── server.js
├── package.json
└── README.md

## Installation

Clone the project and go to the server folder:
cd server
npm install

## Run the server
npm run dev
